DICTIONARY 1

辞典①　AIと話すときの言葉

今日の会話に実際に出てきた「これ・あれ」に、名前をつけます。

コード

code

プログラムの文章そのもの。AIのチャットに出てくる黒い枠のやつがこれ。人間が読むためではなく、機械に読ませるための文字です。

×「この黒いやつ」→ ○「このコード」

HTML

エイチティーエムエル

Webページの設計図。コードの一種で、「ここに地図」「ここに文字」と書いてある紙。設計図であって、家そのものではないのがポイント。

プレビュー／レンダリング

preview / rendering

設計図（HTML）から、実際の見た目を組み立てて表示すること。そうたくんが言っていた「具現化させる」の正式な言い方がこれ。

×「これを具現化させたい」→ ○「このHTMLをプレビューして見せて」

Canvas（Gemini）／ Artifact（Claude）

キャンバス／アーティファクト

チャットの中で、コードを実際の画面として表示してくれる機能。これを知らないと一生コードだけ見せられます。

○「Canvas機能を使って、このコードを画面として表示して」

API ／ APIキー

エーピーアイ

API＝よその会社のデータを分けてもらう窓口。波や潮のデータはここからもらいます。APIキー＝その窓口で見せる自分専用の会員証。

ブラウザ ／ アプリ内ブラウザ

browser

Webを見るためのアプリ（Chrome、Safari）。GeminiやLINEの中で開くページはアプリ内ブラウザといって、閉じると消えてしまいます。ちゃんと残したいときは「外部ブラウザで開く」。今日、右上の「…」から Chrome で開き直したのがこれです。

⚠️ APIキーだけは、絶対に人に見せない

APIキーはクレジットカードの番号と同じだと思ってください。ネットに公開したページのコードの中に貼ったままにすると、他人に拾われて勝手に使われ、その料金があなたに請求されます。

これから GitHub にコードを載せるので、ここは本当に注意。作業に入る前に、AIにこう聞いてください →「APIキーを公開ページに載せずに使う方法を教えて」。もしすでにどこかに貼ってしまっていたら、そのキーを削除して作り直せば大丈夫です（無料でできます）。

DICTIONARY 2

辞典②　ネットに公開するときの言葉

「作ったページのURLを送りたい」を実現するための言葉です。

URL

ユーアールエル

ネット上の住所。ユウキさんが送ってくるリンクはこれ。押すとその住所にある家（ページ）が開きます。

ドメイン

domain

住所のうち「〇〇.com」の部分＝土地代。本来はお金を払って買うもの（.comで年1000円くらい〜、超人気のものは数億円）。

JSBin

ジェイエスビン

今日使った、コードを貼るとその場で表示してくれるサイト。他人の家に間借りしている仮住まいの状態です。便利だけど、自分の住所ではありません。

GitHub

ギットハブ

プログラマがコードを保管する場所。ゲームのセーブデータの倉庫だと思ってください。無料。これから先ずっと使うので、避けて通れません。

GitHub Pages

ギットハブ ペ ージズ

GitHubのおまけ機能。無料で自分のURLがもらえて、作ったページを世界に公開できる。今日のゴールはここ。土地代タダで自分の住所が持てます。

ホーム画面に追加

PWA

Webページを、アプリのようにホーム画面のアイコンから開けるようにする機能。今日もう成功しています。次はウィジェット（ホーム画面に情報を直接出す枠）も相談できます。

HOW TO ASK

AIへの頼み方 5つ

レッスン中にユウキさんが言っていたことを、そのまま使える形にしました。

1. 「分からない」を、どう分からないかまで言う

黙って困っていても伝わりません。分からない種類を伝えると、AIは見せ方を変えてくれます。

文字ばっかりで分かりません。図か画像で説明してください。

2. 自分のレベルを先に宣言する

AIはこちらの知識量を知りません。低く言っても恥ずかしくないし、そのほうが早いです。

私はIT系の知識がゼロで、スマホしか持っていません。専門用語には毎回かんたんな説明をつけてください。

3. 似たサービスを先に見せてもらう

ゼロから考えるより、あるものを見て「これのいいとこ取り」を指定するほうが速い。

同じような既存サービスを5つ挙げて。それぞれの良い点と足りない点も教えて。

4. 案を5つ出させて、審査員になる

1個ずつ直させると時間がかかります。並べて選ぶほうが圧倒的に速い。

デザイン案を5パターン出して。1枚のHTMLにまとめて、ボタンで切り替えられるようにして。

5. 「全部やって」と言う

説明だけで止まっていたら、続きを頼めます。遠慮する相手ではありません。

説明はいいので、できるところは全部やってください。私がやる必要がある操作だけ、順番に指示してください。

まず結論：中古のWindowsノート

4万円だと MacBookは買えません（中古でもだいたい7万円〜）。そして新品の4万円パソコンは、性能が低すぎて後悔します。いちばん賢いのは、企業が使っていた中古のWindowsノート。同じ値段で性能が2〜3倍いいものが買えます。

Windowsを選ぶ理由（Macとの違い）

Windowsはあとからネジを開けて中身を強くできる機種があります。最初は安いのを買って、物足りなくなったらメモリを足す、という買い方ができる。Macはそれをさせない作りなので、足りなくなったら買い替えです。

CHECK LIST

店で見る5つだけ

値札にこの言葉が並んでいます。上から順に大事。

  • メモリ 8GB以上（16GBならベスト） メモリ＝作業机の広さ。狭いと同時にいろいろ開けず、すぐ固まります。4GBは論外。4万円なら8GBが現実的なので、「この機種、あとからメモリを16GBに増やせますか？」と店員さんに聞くのが正解。
  • CPU：Core i5 / Ryzen 5 以上、かつ「第8世代」以降 CPU＝頭の回転の速さ。「Core i5-8250U」のように、i5のあとの数字の頭が8以上ならOK。7以前はWindows 11が入らず、危なくて使えません。ここは妥協しないこと。
  • ストレージ：SSD 256GB以上 ストレージ＝物置の広さ。HDDと書いてあるものは買わない（起動がとても遅い）。必ずSSD。
  • Windows 11 が入っている Windows 10はサポートが終わっているので、11であることを確認。
  • ACアダプタ（充電器）が付いている／バッテリーの状態 中古の落とし穴。充電器が別売りだと数千円かかります。「バッテリーはどれくらい持ちますか」も必ず聞く。
  • いらないもの：Office、大画面、薄さ、見た目 Officeは無料のGoogleドキュメントで足ります。画面は13〜14インチが持ち運びやすい。そのぶんの予算はメモリに回してください。
